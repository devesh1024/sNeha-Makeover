# sNeha's Golden Touch

Build a Premium Beauty Parlour Website for “sNeha's Makeover”

Create a complete, polished, production-quality responsive website for a boutique beauty parlour named “sNeha's Makeover”.

This is a real local beauty parlour operated by a professional beautician, so the website should feel like a premium personal beauty brand, not like a generic salon template.

The website should primarily showcase:

The parlour and its brand

Beauty services

Makeup, nail and hairstyle work performed by the parlour

A visual portfolio/gallery

A catalogue of products available at the parlour

Contact and appointment/inquiry options

The website should be frontend-focused, but use Supabase for lightweight backend functionality and data management.
